# 八字知识卡 第一批

本批共35张。事业、爱情、家庭、财富、子女、岁运、合盘各5张。下面是可阅读版本 对应JSON文件保留全部字段、精确引用行号与文件校验值。

全部卡片状态为draft 仅供内容整理和审校。AI已检查引文是否出现在指定版本与行号 但未获命理专家审核。现代反思问题单独标记 不冒称古籍判断。适用条件为人工检查清单 尚未实现可执行推断逻辑。

古籍转录尚未逐字校勘。来源分歧不能靠AI任选一条消除。来源问题见 [source_quality.json](source_quality.json)。合盘5张全部是分析工作流或证据缺口 没有已验证的双盘配对、吉凶评分或成功率模型。

## 数据与接口

每个主题的JSON数组含：id、主题、卡片类型、证据关系、原则、原文引用、版本与行号、所需输入、适用检查、例外、允许解释、禁止推论、现代反思、内容路由样例、相关卡与审核状态。

```bash
python knowledge_tools.py validate
python knowledge_tools.py search --topic wealth --include-drafts
python knowledge_tools.py search 比劫 --include-drafts
python bazi_resources.py serve
```

本地接口：`GET http://127.0.0.1:8765/cards?topic=wealth&include_drafts=true`。默认排除草稿。当前正式规则数为0。此接口提供卡片检索 不会自动对人的命盘进行判断。

新增或修改卡片后须重新运行校验与测试。引用文本、行号或文件校验值不一致时 检索会拒绝返回卡片。批准发布需要记录专家审核人、时间及可发布状态；这只是记录要求 不代替真实的人工审核。

样例均为合成的内容路由例子 不是预测准确率测试。现阶段验证的是来源与产品边界 不是证明命理预测有效。
