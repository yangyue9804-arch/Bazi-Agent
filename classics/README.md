《子平真诠》传统题清沈孝瞻撰。不同版本篇数和编次可能不同 本目录不把47章提取版称为所有版本的全集。原来源第09与10章出现先后颠倒 本档按章号排列。文本未与影印底本逐字校勘 可能存在转录误字、标点差异和底本缺漏。

维基文库的《滴天髓》页面收的是辑要电子本。《滴天髓阐微》另存一份 不将不同注本混称同一本原文。原注和任氏解释保留来源标签 其思想须分别审查。

## 查找正文

在仓库根目录执行：

```bash
python bazi_resources.py passages 乙木 --limit 5
python bazi_resources.py passages 用神
python bazi_resources.py serve
```

本地API：`GET http://127.0.0.1:8765/passages?q=乙木&limit=5`。

返回原文段落、书名、章节、仓库文件路径、起始行号、来源及校验值。当前是精确关键词匹配 支持空格分隔多个关键词并同时匹配。不会自动生成命理解读 也未实现简繁体统一或语义向量检索。例如“乙木”在简繁两种文本中相同 但“伤官”与“傷官”需分别查询。

## 来源与使用说明

维基文库转录衍生文件署名为维基文库贡献者 并按来源所标示的 CC BY-SA 4.0 保存。许可链接：https://creativecommons.org/licenses/by-sa/4.0/ 。文件头和manifest中保留来源页面、固定修订版本和整理方式。相同方式共享说明适用于相应电子文本整理文件 不表示本项目代码或独立新增内容自动采用相同许可。

《子平真诠》文件仅保留明确标记的古籍原文 不复制来源的徐氏序注、评注段落或现代解释。原始定位仓库为liangqis/Chinese-minglixue 并记录来源Git blob。出处归档不构成对所有现代注释的商用授权。

`manifest.json` 记录每份正文的SHA-256、来源与版次说明。其 `review_status` 为 `transcription_unverified` 且 `rules_approved` 为false。存入正文不等于内容已校勘或可以不经审查直接用于断事。

古籍中保留了历史性的性别、疾病、寿夭、贫富与吉凶判语。它们作为文献资料保存 不应原样变成针对现代用户的诊断、保证或人生定论。
