# 知命网站与后台架构

私密内测网站：https://zhiming-yue.roastedcashewhut.chatgpt.site/

本仓库是古籍与知识卡的版本源。网站的前端与服务端代码由Sites源仓库管理并构建部署。

## 已接通

用户输入公历生日、时刻与出生城市 → POST /api/chart → 时区与夏令时解析 → 统一UTC+8口径排盘 → 返回四柱、天干十神、藏干与显性五行计数。

报告页选择主题 → GET /api/knowledge → 返回从本仓库固定提交同步的知识卡及原文引用。

当前知识快照为a117851a8a0c60b8ddb77a8e52b75609288aa88f。通过构建前同步与重新部署更新 不是每个用户请求时扫描整个GitHub仓库。用户生日不会发送到GitHub 不会成为Git提交。当前应用不主动保存生日档案。

## 当前功能范围

- 单人真实四柱排盘。
- 双人独立排盘与可计算的日主五行、日支六合六冲事实对照。
- 七个主题与35张待审校知识卡。
- 原文展开与固定版本来源链接。
- 古籍入口与今日干支展示。
- 手机优先的响应式界面。

排盘口径：lunar-javascript 1.7.7 sect 2。输入出生地民用时间 统一转换北京时间UTC+8。日柱按午夜换日 晚子时时柱采用该库实现。不使用真太阳时。支持1950年起的日期与页面所列城市；海外出生应留意统一北京时间与出生地当地排盘口径的差别。时辰未知时不补算时柱 对可能变化的年月日柱保持未知。

## 尚未接通

没有自动旺衰、格局或喜用判定 没有根据条件判断知识卡是否适用于某个人 没有外部语言模型调用或个人解读生成 也没有大运、个人每日吉凶、婚姻成败概率、支付与账户档案。当前内容是主题知识参考 不是已经生成的个人预测。

完整产品下一层应为：排盘事实 → 经审核的条件判断 → 命中规则及引用证据包 → AI组织用户能理解的报告 → 输出校验与版本记录。语言模型密钥应只放在后台密钥管理中。

## 验证

8项计算测试涵盖上游参考盘、晚子时、跨时区同一时刻、夏令时跳时及重复时刻、未知时辰、无效输入、双人计算与十神极性。TypeScript检查与部署构建通过。浏览器已走通单人、双人排盘及引用展开。网站已发布且保持所有者私密访问 正式网址需使用所有者ChatGPT账户登录。
